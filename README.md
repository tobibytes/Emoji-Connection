# Emoji-Connection

A real-time multiplayer game where players race to walk a graph of related emojis. Connect over a TCP socket, get assigned a start and goal emoji, and use `get_children` to traverse the graph — fastest player to reach the goal wins.

The catch: the graph itself is generated by an LLM. On startup, an OpenAI agent produces an emoji adjacency list (e.g. `😀 → [😂, 😢, 😡]`), and that becomes the round's playfield.

## Pieces

| File | Role |
| --- | --- |
| `main.py` | Wires the server, connection manager, and game logic together |
| `server.py` | `ConnectionManager` singleton — threaded TCP server, tracks `user ↔ socket` |
| `logic.py` | `GameLogic` singleton — graph state, per-user scores, round timer, start/destination |
| `generate.py` | Calls an OpenAI Agent that returns a JSON emoji adjacency list |
| `client.py` | Minimal TCP client to play |
| `utils.py` | Username validation, helpers |

## How a round goes

1. `GameLogic` starts and asks the agent to generate an emoji graph.
2. Players connect, pick a username.
3. The server picks a `start_value` and `dest_value` from the graph.
4. Each player `get_children`s their way through the graph; the server tracks steps and time.
5. Either a player reaches `dest_value` and wins, or the timer (`GAME_TIME_MINUTES = 1`) runs out.

## Run it

```sh
# 1. Install deps (uses uv)
uv sync

# 2. Set the OpenAI key for graph generation
export OPENAI_API_KEY=sk-...
# optional:
export SERVER_HOST=0.0.0.0
export SERVER_PORT=60009

# 3. Start the server
uv run python main.py

# 4. Connect with the client (in another shell)
uv run python client.py
```

## Stack

Python 3.12+ · `openai-agents` (graph generation) · `socket` · `threading` · `asyncio` · `dotenv`
